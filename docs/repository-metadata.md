# Repository metadata

This file is the source of truth for the project description and discoverability
copy. The GitHub **About** panel is repository-account metadata and must be
updated by an owner or administrator in the hosting service; a local commit
cannot change its description, website, topics, stars, watchers, forks,
releases, packages, or contributor count.
